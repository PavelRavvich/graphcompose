# Идеи для примеров (Examples)

## Для программистов
- **Job Scout Workflow**: Автоматический поиск вакансий, фильтрация, мэтчинг резюме и подача заявок.
- **CI/CD Workflow**: Агент-ревьюер для PR (анализ изменений, прогон линтеров, генерация отчета об уязвимостях).
- **Debugging & Logs Workflow**: Парсинг логов ошибок (например, из Datadog/Sentry), анализ стектрейса, поиск решения и предложение патча.
- **Codebase & Docs Analysis Workflow**: Индексация большой кодовой базы/документации, RAG-ассистент для онбординга новых разработчиков.

## Для инвесторов (VC) и стартапов
- **Market Analysis Workflow**: Сбор данных по нише, анализ трендов, оценка объема рынка.
- **Startup Context Analysis Workflow**: Глубокий скоринг конкретного стартапа (проверка фаундеров, конкурентный ландшафт, технологический стек, оценка рисков).
- **Fundraising Workflow (для фаундеров)**: Поиск релевантных VC-фондов, анализ их портфеля, генерация персонализированного питча/cold email для партнеров.
