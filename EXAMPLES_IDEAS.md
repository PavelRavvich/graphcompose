# Идеи для примеров (Examples)

## Для программистов
- **Job Scout Workflow**: Автоматический поиск вакансий, фильтрация, мэтчинг резюме и подача заявок.
- **CI/CD Workflow**: Агент-ревьюер для PR (анализ изменений, прогон линтеров, генерация отчета об уязвимостях).
- **Debugging & Logs Workflow**: Парсинг логов ошибок (например, из Datadog/Sentry), анализ стектрейса, поиск решения и предложение патча.
- **Codebase & Docs Analysis Workflow**: Индексация большой кодовой базы/документации, RAG-ассистент для онбординга новых разработчиков.

## Для инвесторов (VC) и стартапов
- **Market Analysis Workflow**: Сбор данных по нише, анализ трендов, оценка объема рынка.
- **Startup Context Analysis Workflow**: Глубокий скоринг конкретного стартапа (проверка фаундеров, конкурентный ландшафт, технологический стек, оценка рисков).
- **Fundraising Workflow (для фаундеров)**: Поиск релевантных VC-фондов, анализ их портфеля, генерация персонализированного питча/cold email для партнеров.
- **Legal Review Workflow**: Анализ учредительных документов и IP-соглашений (Intellectual Property) между фаундерами на предмет подводных камней, распределения долей и перехода прав.

## Для Сейлзов и Маркетологов (B2B)
- **Cold Outreach Workflow**: Парсинг LinkedIn профиля и новостей компании для генерации гипер-персонализированного холодного письма, которое звучит максимально "человечно".
- **Competitor Analysis Workflow**: Извлечение цен, фич и позиционирования со страниц конкурентов, формирование сводной таблицы (CSV/Excel) со слабыми местами конкурентов.

## Для HR и Рекрутеров
- **Candidate Screening Workflow**: Массовая параллельная обработка (через `nextEach`) сотен PDF-резюме, сравнение с требованиями вакансии и формирование шортлиста топ-5 кандидатов с аргументацией.

## Для Продакт-менеджеров (PM)
- **Feedback Triage Workflow**: Автоматическая категоризация тикетов из поддержки (баги, UX, новые фичи), группировка болей пользователей и драфтинг Product Requirements Document (PRD).

## Для Web3 / Крипты
- **Tokenomics & Whitepaper Analyzer**: Поиск "красных флагов" в whitepaper (графики разлоков, распределение токенов), сравнение с бенчмарками и выжимка рисков для инвесторов.
